# 财经日历浏览器插件

这是一个基于 Manifest V3 的浏览器插件（Chrome / Edge）。

## 本地安装（开发者模式）
1. 打开浏览器扩展管理页：
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
2. 打开“开发者模式”。
3. 点击“加载已解压的扩展程序（Load unpacked）”。
4. 选择当前项目目录。
5. 点击工具栏中的“财经日历”图标，即可打开插件弹窗。

## 功能
- 月视图显示财经事件
- 点击日期快速填充新增事件日期
- 新增/删除事件
- 本地持久化（localStorage）

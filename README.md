# 财经日历浏览器插件（新标签页版）

这是一个基于 Manifest V3 的 Chrome / Edge 插件。
安装后，打开新标签页会直接进入财经日历。

## 安装方式（开发者模式）
1. 打开扩展页：
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
2. 打开“开发者模式”。
3. 点击“加载已解压的扩展程序（Load unpacked）”。
4. 选择当前项目目录。

## 使用方式
- 打开新标签页，即可看到月历。
- 每天格子右下角有 `+ 添加` 按钮，可直接新增事件。
- 已有事件支持 `编辑` / `删除`。
- 事件保存在本地 `localStorage`。

# 金十快讯中文播报（Chrome 扩展）

这个浏览器插件会监听页面 `https://www.jin10.com/` 的**新增快讯**，并只朗读金十页面中标记为重点（红色样式）的快讯。

## 功能

- 只监听并朗读**新增**快讯（不朗读页面现有历史内容）
- 只朗读重点红色快讯（匹配 `.jin-flash-item.flash.is-important`）
- 自动去重，避免重复播报
- 中文语音优先（`zh-CN`）
- 可在插件弹窗中调节：开关、语音、语速、音调、音量（语音下拉项使用中文标签）
- 支持一键停止当前播报

## 安装方式（开发者模式）

1. 打开 Chrome，进入 `chrome://extensions/`
2. 右上角开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本项目目录

## 使用说明

1. 打开 `https://www.jin10.com/`
2. 保持标签页开启，等待快讯更新
3. 扩展会自动朗读后续新增的重点红色快讯（`is-important`）
4. 可点击扩展图标，在弹窗中选择语音并调整参数

## 注意

- 当前按金十页面结构匹配：重点快讯容器类名为 `.jin-flash-item.flash.is-important`。
- 语音效果依赖系统/浏览器可用语音包；如未安装中文语音包，插件会提示并跳过播报，避免用英文音色朗读中文。
- 金十页面 DOM 结构若发生变化，可能需要同步更新 `content.js` 中的选择器。
